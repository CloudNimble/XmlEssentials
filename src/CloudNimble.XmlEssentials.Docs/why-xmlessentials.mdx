# Why XmlEssentials?

Microsoft declined to ship `System.Text.Xml` ([dotnet/runtime#125299](https://github.com/dotnet/runtime/issues/125299), closed as not planned, March 2026). XmlEssentials is that stack: System.Text.Json-shaped API, zero `System.Xml*` dependency.

| | |
|---|---|
| Package | `XmlEssentials` |
| Assembly | `CloudNimble.XmlEssentials` |
| Namespace | `CloudNimble.Text.Xml` |

Install: `dotnet add package XmlEssentials` then `using CloudNimble.Text.Xml`.
