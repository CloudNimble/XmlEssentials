## Summary

Specifies the local name of the XML element or attribute that a property or field is serialized as. This class cannot be inherited.

## Usage

Apply `[XmlPropertyName]` to a property or field to set its XML name. It is the counterpart of `[JsonPropertyName]`, and it works whether the member is written as an element or as an XML attribute.

```csharp
[XmlPropertyName("title")]
public string? Name { get; set; }
```

In the following type, `Name` is written as the `title` element.

```csharp
[XmlRoot("product")]
public sealed class CatalogItem
{
    [XmlAttribute("sku")]
    public string? Sku { get; set; }

    [XmlPropertyName("title")]
    public string? Name { get; set; }

    [XmlElement("unit-price")]
    public decimal UnitPrice { get; set; }
}
```

Serializing a `CatalogItem` with these attributes produces the following XML:

```xml
<product sku="KB-101"><title>Keyboard</title><unit-price>49.95</unit-price></product>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/08_CustomizeNames.cs)

## Remarks

The name overrides any naming policy, and takes precedence over the name set by [XmlElementAttribute](/api-reference/CloudNimble/Text/Xml/Serialization/XmlElementAttribute),
[XmlAttributeAttribute](/api-reference/CloudNimble/Text/Xml/Serialization/XmlAttributeAttribute), or [XmlArrayAttribute](/api-reference/CloudNimble/Text/Xml/Serialization/XmlArrayAttribute) on the same member. This attribute is
analogous to `JsonPropertyNameAttribute` in `System.Text.Json`.

## Considerations

- The name takes precedence over a name set in `[XmlElement]`, `[XmlAttribute]`, or `[XmlArray]` on the same member, and a naming policy doesn't convert it.
- The attribute sets the local name only. To set a namespace, use the `Namespace` property of `[XmlElement]`, `[XmlAttribute]`, or `[XmlArray]`.
- On a collection with no `[XmlArray]`, the name applies to each repeated item. With `[XmlArray]`, it names the wrapper element.
- Two members of one type can't have the same element name or the same attribute name. The serializer throws an `InvalidOperationException` the first time it uses such a type.
- The attribute isn't read on enumeration members. Enumeration values are always written as their C# names or as numbers. To write other names, use a [custom converter](/guides/custom-converters).
