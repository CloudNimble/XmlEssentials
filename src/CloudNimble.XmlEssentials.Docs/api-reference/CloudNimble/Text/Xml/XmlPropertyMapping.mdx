## Summary

How an unannotated property or field is mapped: child element or XML attribute.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Element` | 0 | Write the member as a child element. This is the default. |
| `Attribute` | 1 | Write unannotated simple members as XML attributes. Nested objects stay child elements, and their
unannotated simple members are also attributes (the option applies at every type). Collections stay
child elements. Per-member `[XmlElement]`, `[XmlAttribute]`, or `[XmlText]` still wins. |
