## Best Practices

# Best Practices

Do not put `--` in comment text. Prefer `CommentHandling.Allow` on `XmlDocument` when comments are part of the contract.

## Patterns

# Patterns

Immutable `XmlDocument` keeps prolog/epilog comments for `WriteTo` without exposing them as `RootElement` children. Mutable trees only keep comments you add as children.

## Considerations

# Considerations

Comments containing `--` or ending in `-` throw on write. `XmlNode.Parse` discards prolog comments; parse with `XmlDocument` and `CommentHandling.Allow` when they must round-trip, then clone.
