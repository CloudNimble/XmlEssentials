## Summary

Opaque resume state for [Utf8XmlReader](/api-reference/CloudNimble/Text/Xml/Utf8XmlReader).

## Remarks

The public surface matches `Utf8JsonReader`: only [XmlReaderState.Options](/api-reference/CloudNimble/Text/Xml/XmlReaderState#options) is visible.
[Utf8XmlReader.CurrentState](/api-reference/CloudNimble/Text/Xml/Utf8XmlReader#currentstate) copies an immutable snapshot so two readers
never share mutable element or namespace stacks.
