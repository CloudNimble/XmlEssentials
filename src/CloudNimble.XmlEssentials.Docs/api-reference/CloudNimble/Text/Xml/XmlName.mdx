## Summary

A namespace-qualified XML name: local name, namespace URI, and optional prefix.

## Remarks

Equality is the ordinal combination of [XmlName.LocalName](/api-reference/CloudNimble/Text/Xml/XmlName#localname) and [XmlName.NamespaceUri](/api-reference/CloudNimble/Text/Xml/XmlName#namespaceuri).
[XmlName.Prefix](/api-reference/CloudNimble/Text/Xml/XmlName#prefix) is serialization sugar and is not significant for equality or mapping.

## Constructors

### <Icon icon="hammer" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> .ctor

Creates a qualified name.

#### Syntax

```csharp
public XmlName(string localName, string namespaceUri = null, string prefix = null)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `localName` | `string` | The local name. Cannot be null or whitespace. |
| `namespaceUri` | `string?` | The namespace URI, or null for no namespace. |
| `prefix` | `string?` | The prefix, or null for none. Not used in equality. |

#### Examples

```csharp
var name = new XmlName("Person", "https://example.com", "e");
Console.WriteLine(name); // e:Person
```

#### Remarks

Pass a namespace URI without a prefix when comparing names. Prefix is only written
by [XmlName.ToString](/api-reference/CloudNimble/Text/Xml/XmlName#tostring) when it is non-empty.
