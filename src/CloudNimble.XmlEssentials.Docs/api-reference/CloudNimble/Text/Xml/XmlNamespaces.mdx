## Remarks

The `xml` and `xmlns` prefixes are bound to [XmlNamespaces.Xml](/api-reference/CloudNimble/Text/Xml/XmlNamespaces#xml) and [XmlNamespaces.Xmlns](/api-reference/CloudNimble/Text/Xml/XmlNamespaces#xmlns)
for the lifetime of a document. Do not rebind them.
