## Summary

Immutable XML declaration captured when an [XmlDocument](/api-reference/CloudNimble/Text/Xml/XmlDocument) is parsed.

## Usage

# Usage

`XmlDocument.Declaration` is an optional `XmlDeclarationInfo` captured at parse time.

```csharp
using var document = XmlDocument.Parse("<?xml version=\"1.0\" encoding=\"utf-8\" standalone=\"yes\"?><e/>");
var declaration = document.Declaration!.Value;
Console.WriteLine(declaration.Version);    // 1.0
Console.WriteLine(declaration.Encoding);   // utf-8
Console.WriteLine(declaration.Standalone); // true
```

## Remarks

Mutable trees use `CloudNimble.Text.Xml.Nodes.XmlDeclarationNode` instead.

## Examples

# Examples

Version 1.1 is recorded when the declaration says so:

```csharp
using var document = XmlDocument.Parse("<?xml version=\"1.1\" encoding=\"utf-8\"?><e/>");
document.Declaration!.Value.Version; // 1.1
```

## Best Practices

# Best Practices

Read `Declaration` only while the document is undisposed. Treat a missing declaration as XML 1.0 with no standalone flag.

## Patterns

# Patterns

**Round-trip.** `XmlDocument.WriteTo` writes the captured declaration (version and standalone) before the root. The writer is marked so it does not emit a second declaration.

## Considerations

# Considerations

This is a readonly struct. Encoding is always `utf-8` for documents this stack accepts. `Standalone` is null when the pseudo-attribute was omitted.

Mutable trees use `Nodes.XmlDeclarationNode` instead. Mutating that type cannot change `XmlDocument.Declaration`.
