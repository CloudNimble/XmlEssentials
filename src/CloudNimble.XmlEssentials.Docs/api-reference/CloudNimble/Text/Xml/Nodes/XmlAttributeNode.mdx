## Summary

A mutable XML attribute.

## Usage

`XmlAttributeNode` is an attribute in the mutable tree: a `LocalName`, a `Value`, and, for an attribute in a namespace, a `NamespaceUri` and a `Prefix`. Attributes live in the `Attributes` list of an `XmlElementNode`.

Most code doesn't create one directly. `XmlElementNode.SetAttribute` creates or updates an attribute, and `Attributes["name"]` returns the node so that you can read or change its `Value`. Construct an `XmlAttributeNode` yourself when you need to choose the prefix.

```csharp
var order = (XmlElementNode)XmlNode.Parse("""<Order id="1042" status="open" draft="true"/>""")!;

order.SetAttribute("status", "shipped");
order.SetAttribute("carrier", "Contoso Freight");
order.Attributes["id"]!.Value = "1043";

XmlAttributeNode draft = order.Attributes["draft"]!;
order.Attributes.Remove(draft);

output.WriteLine(order.ToString());
```

The code produces the following output:

```xml
<Order id="1043" status="shipped" carrier="Contoso Freight"/>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/30_ChangeWithXmlNode.cs)

## Considerations

- An attribute without a prefix is in no namespace, even when its element is in a default namespace. To put an attribute in a namespace, give it a `NamespaceUri` and a `Prefix`. With a namespace and no prefix, the writer generates one:

  ```csharp
  var item = new XmlElementNode("Item");
  item.SetAttribute("unit", "kg", "urn:example:units");
  output.WriteLine(item.ToString());

  var broken = new XmlElementNode("Item", namespaceUri: null, prefix: "u");
  try
  {
      broken.ToString();
  }
  catch (XmlException ex)
  {
      output.WriteLine(ex.Message);
  }
  ```

  The code produces the following output:

  ```text
  <Item xmlns:ns1="urn:example:units" ns1:unit="kg"/>
  Prefixed names require a namespace URI.
  ```

- A namespace declaration is an attribute too. In a parsed tree, `xmlns="..."` has the local name `xmlns`, and `xmlns:dc="..."` has the prefix `xmlns` and the local name `dc`; both report `XmlNamespaces.Xmlns` as their namespace.
- `Value` is the plain value. Escaping happens when the attribute is written. A `null` value, prefix, or namespace is stored as an empty string.
- `LocalName` rejects `null`, an empty string, and white space.
- `ToString` on an attribute throws an `XmlException`, because an attribute can't be written outside a start tag. Read `Value`.
- An attribute has one parent. Adding it to a second element throws; use `DeepClone` to copy it.
