## Summary

Options for [Utf8XmlWriter](/api-reference/CloudNimble/Text/Xml/Utf8XmlWriter).

## Usage

# Usage

Pass a constructed options struct into `Utf8XmlWriter`:

```csharp
var options = new XmlWriterOptions
{
    Indented = true,
    NewLine = "\n",
    OmitXmlDeclaration = true,
    MaxDepth = 32,
};
using var writer = new Utf8XmlWriter(buffer, options);
```

Use the parameterless constructor so `IndentCharacter` is space and `NewLine` is `Environment.NewLine`.

## Remarks

A max-* of 0 means the default from the DoS table. Construct with
`new XmlWriterOptions()` so indent defaults apply.

## Examples

# Examples

Pretty-print a fragment:

```csharp
new XmlWriterOptions
{
    OmitXmlDeclaration = true,
    Indented = true,
    IndentSize = 2,
    NewLine = "\n",
};
```

XML 1.1 with a BOM:

```csharp
new XmlWriterOptions
{
    Version = XmlVersion.Version11,
    EmitByteOrderMark = true,
};
```

## Best Practices

# Best Practices

- Always write `new XmlWriterOptions()` rather than `default`.
- Set `NewLine` explicitly (`"\n"` or `"\r\n"`) when tests or files must not depend on the OS.
- Leave `EmitByteOrderMark` false unless an interoperable consumer requires `EF BB BF`.

## Patterns

# Patterns

**Fragments.** `OmitXmlDeclaration = true` when the caller wraps the bytes in a larger document.

**DoS.** Set `MaxDepth`, `MaxAttributeCount`, and `MaxNameByteCount` together. Zero means “use the default,” not “unlimited.”

**SkipValidation.** Turns off name and well-formedness checks. Limits still apply. Unclosed `Dispose` does not throw.

## Considerations

# Considerations

`default(XmlWriterOptions)` is all zeros: `IndentCharacter` is NUL, `NewLine` is null, every max-* is 0. The writer treats NUL indent as space, null/empty newline as `Environment.NewLine`, and 0 max-* as the table defaults (64 / 1000 / 1024).

`Version` defaults to XML 1.0. XML 1.1 emits `version="1.1"` and writes RestrictedChar as numeric character references.

`EmitByteOrderMark` is false. `Standalone` is omitted from the declaration when null.
