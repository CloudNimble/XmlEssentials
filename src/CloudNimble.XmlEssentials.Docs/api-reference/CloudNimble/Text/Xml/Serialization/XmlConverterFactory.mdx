## Summary

Creates converters for a family of types, such as every enum or every closed form of a generic type.

## Usage

A factory is a converter that doesn't convert anything itself. It tells the serializer which types it covers, in `CanConvert`, and creates the converter for each one, in `CreateConverter`. Use it for a family of types that one `XmlConverter<T>` can't serve: every enumeration, or every closed form of a generic type.

```csharp
public sealed class KebabCaseEnumConverterFactory : XmlConverterFactory
{
    public override bool CanConvert(Type typeToConvert)
    {
        return typeToConvert.IsEnum;
    }

    public override XmlConverter? CreateConverter(Type typeToConvert, XmlSerializerOptions options)
    {
        Type converterType = typeof(KebabCaseEnumConverter<>).MakeGenericType(typeToConvert);
        return (XmlConverter?)Activator.CreateInstance(converterType);
    }
}
```

Register a factory as you would a converter: add an instance to `XmlSerializerOptions.Converters`, or name the factory type in `[XmlConverter]`.

`CreateConverter` must return an `XmlConverter<T>` whose `T` is exactly `typeToConvert`. The class is the counterpart of `JsonConverterFactory` in System.Text.Json.

## Examples

### Write every enumeration in kebab case

The factory in the usage section creates one of these converters for each enumeration:

```csharp
public sealed class KebabCaseEnumConverter<TEnum> : XmlConverter<TEnum>
    where TEnum : struct, Enum
{
    public override TEnum Read(ref Utf8XmlReader reader, Type typeToConvert, XmlSerializerOptions options)
    {
        TEnum value = default;
        if (reader.IsEmptyElement)
        {
            return value;
        }

        while (reader.Read() && reader.TokenType is not XmlTokenType.EndElement)
        {
            if (reader.TokenType is XmlTokenType.Text)
            {
                value = Parse(reader.GetString()!);
            }
        }

        return value;
    }

    public override void Write(Utf8XmlWriter writer, TEnum value, XmlSerializerOptions options)
    {
        writer.WriteStringValue(XmlNamingPolicy.KebabCaseLower.ConvertName(value.ToString()));
    }

    private static TEnum Parse(string text)
    {
        foreach (TEnum candidate in Enum.GetValues<TEnum>())
        {
            if (XmlNamingPolicy.KebabCaseLower.ConvertName(candidate.ToString()) == text)
            {
                return candidate;
            }
        }

        throw new XmlException($"'{text}' is not a value of {typeof(TEnum).Name}.");
    }
}
```

With the factory registered, both enumeration members of `OrderTracking` use it:

```csharp
var options = new XmlSerializerOptions { OmitXmlDeclaration = true };
options.Converters.Add(new KebabCaseEnumConverterFactory());

var tracking = new OrderTracking
{
    OrderId = 1042,
    Status = OrderStatus.ReadyToShip,
    Priority = Priority.Rush,
};

string xml = XmlSerializer.Serialize(tracking, options);
output.WriteLine(xml);

OrderTracking? copy = XmlSerializer.Deserialize<OrderTracking>(xml, options);
output.WriteLine($"Order {copy!.OrderId}: {copy.Status}, {copy.Priority}");
```

The code produces the following output:

```text
<OrderTracking><OrderId>1042</OrderId><Priority>rush</Priority><Status>ready-to-ship</Status></OrderTracking>
Order 1042: ReadyToShip, Rush
```

## Considerations

- **The returned converter must match the type exactly.** If `CreateConverter` returns `null`, the serializer throws `InvalidOperationException`. It also throws when the converter returned is for another type.
- **`CreateConverter` runs once for each type and options instance.** The serializer keeps the converter it returns, so the work of creating it isn't repeated.
- **Order in the `Converters` list matters.** The first converter or factory whose `CanConvert` returns `true` is used. Put a converter for one specific type before a factory that also covers it.
- **Reflection in a factory isn't safe for Native AOT.** A factory that calls `MakeGenericType` or `Activator.CreateInstance` on a constructed type needs code the ahead-of-time compiler may not have produced. In an AOT application, construct the converters directly, for example in a `switch` on `typeToConvert`.
- **Source generation.** A generated converter in the default mode asks the options for a converter only for enumeration members, so an enumeration factory such as the one in the example applies there. A factory for classes or structs doesn't.
- **A factory makes `CanConvert` broad, so keep it precise.** A factory that returns `true` for types it can't handle hides the built-in converter for those types.
