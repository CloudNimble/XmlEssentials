## Usage

# Usage

```csharp
var node = new XmlDeclarationNode
{
    Version = "1.1",
    Encoding = "utf-8",
    Standalone = false,
};
```

Immutable documents use `XmlDeclarationInfo` instead.

## Examples

# Examples

```csharp
new XmlDeclarationNode { Standalone = true }.ToString();
// <?xml version="1.0" encoding="utf-8" standalone="yes"?>
```

## Best Practices

# Best Practices

Keep `Encoding` as `utf-8`. This stack does not write other encodings.

## Patterns

# Patterns

Use this type only in a mutable tree you assemble by hand. Parsed `XmlDocument` instances never expose it.

## Considerations

# Considerations

`WriteTo` emits a raw declaration. It must be the first output on that writer. `XmlDocument.WriteTo` uses `XmlDeclarationInfo`, not this type.
