## Summary

Sets the element name of collection items of type *T*.

## Usage

Apply `[XmlArrayItem]` together with [`[XmlArray]`](/api-reference/CloudNimble/Text/Xml/Serialization/XmlArrayAttribute) to name the item elements inside the wrapper element of a collection.

```csharp
public sealed class Album
{
    public string? Title { get; set; }

    [XmlArray("Tracks")]
    [XmlArrayItem("Track")]
    public List<string>? Tracks { get; set; }
}
```

```csharp
var album = new Album { Title = "Kind of Blue", Tracks = ["So What", "Freddie Freeloader"] };
var options = new XmlSerializerOptions { WriteIndented = true, NewLine = "\n", OmitXmlDeclaration = true };

string xml = XmlSerializer.Serialize(album, options);
output.WriteLine(xml);
```

The code produces the following output:

```xml
<Album>
  <Title>Kind of Blue</Title>
  <Tracks>
    <Track>So What</Track>
    <Track>Freddie Freeloader</Track>
  </Tracks>
</Album>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/12_SerializeCollections.cs)

## Type Parameters

- `T` - The CLR item type.

## Considerations

- The attribute has an effect only on a collection that also has `[XmlArray]`. On a collection with no wrapper, the repeated elements keep the member's name. To rename those, use `[XmlElement("Name")]` or `[XmlPropertyName("Name")]` on the member.
- Without the attribute, each item of a wrapped collection is named after its .NET type, converted by the element naming policy.
- A name set here isn't converted by a naming policy.
- The serializer doesn't read the `Namespace` property.
- For collections whose items are of different derived types, see [Polymorphism](/guides/polymorphism).
