## Summary

A mutable CDATA node.

## Usage

# Usage

```csharp
root.Add(new XmlCDataNode("<raw>"));
```

`InnerText` includes CDATA payloads along with text nodes.

## Examples

# Examples

```csharp
var root = new XmlElementNode("e");
root.Add(new XmlCDataNode("x"));
root.ToString(); // <e><![CDATA[x]]></e>
```

## Best Practices

# Best Practices

Keep CDATA as a child of an element. Do not put `]]>` in the value.

## Patterns

# Patterns

Use CDATA when the payload is markup-like text you do not want escaped as `&lt;`.

## Considerations

# Considerations

`WriteTo` calls `WriteCData`. A payload containing `]]>` throws. CDATA is significant whitespace; it is not skipped by whitespace options on the mutable tree.
