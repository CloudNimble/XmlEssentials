## Summary

Default options for a source-generated [XmlSerializerContext](/api-reference/CloudNimble/Text/Xml/Serialization/XmlSerializerContext). Analogous to
`JsonSourceGenerationOptionsAttribute`. Constructor [XmlSerializerOptions](/api-reference/CloudNimble/Text/Xml/XmlSerializerOptions) win when
the consumer passes `new AppXmlContext(options)`.

## Usage

Apply `[XmlSourceGenerationOptions]` to a source-generated context to set the options its `Default` instance uses and the mode the generator works in.

```csharp
[XmlSourceGenerationOptions(
    OmitXmlDeclaration = true,
    PropertyNamingPolicy = XmlKnownNamingPolicy.CamelCase)]
[XmlSerializable(typeof(Order))]
public partial class CamelCaseOrderXmlContext : XmlSerializerContext
{
}
```

```csharp
string xml = XmlSerializer.Serialize(CreateOrder(), CamelCaseOrderXmlContext.Default.Order);
output.WriteLine(xml);
```

The code produces the following output:

```xml
<order id="1042"><customer>Ada</customer><Line><quantity>1</quantity><sku>KB-01</sku></Line><Line><quantity>2</quantity><sku>MS-02</sku></Line></order>
```

The attribute seeds the options of `Default` and of a context created with the parameterless constructor. A context created with `new CamelCaseOrderXmlContext(options)` uses the options you pass instead.

The attribute is the counterpart of `JsonSourceGenerationOptionsAttribute` in System.Text.Json. An attribute argument must be a constant, so naming policies are chosen with the `XmlKnownNamingPolicy` enumeration and not with an `XmlNamingPolicy` instance.

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/32_UseSourceGeneration.cs)

## Considerations

- **The generator acts on some of the properties.** `GenerationMode`, `WriteIndented`, `OmitXmlDeclaration`, `DefaultNamespace`, `PropertyNamingPolicy`, `ElementNamingPolicy`, `AttributeNamingPolicy`, and `IncludeFields` take effect.
- **The other properties aren't copied to the options.** Setting `NilHandling`, `DefaultIgnoreCondition`, `DefaultPropertyMapping`, `DiscriminatorPlacement`, `EnumHandling`, `EmitByteOrderMark`, `IgnoreReadOnlyFields`, `IgnoreReadOnlyProperties`, `MaxDepth`, `PropertyNameCaseInsensitive`, `RespectNullableAnnotations`, `UseStringEnumConverter`, or `XmlVersion` leaves the options of `Default` at their defaults. To use those settings, pass an `XmlSerializerOptions` instance to the constructor of a context in metadata mode.
- **Naming policies are applied twice.** The generator fixes member names in the generated converters at compile time, and sets the policy on the default options, which name the document element at run time. If you pass your own options to the constructor, set the same policy on them, or the document element and its members follow different policies.
- **Indented output uses `Environment.NewLine`.** The attribute has no `NewLine` property. Pass options to the constructor to choose the line ending.
