## Usage

# Usage

```csharp
root.Add(new XmlTextNode("Ada"));
root.InnerText = "Ada"; // replaces children with one text node
```

## Examples

# Examples

```csharp
var root = new XmlElementNode("e");
root.Add(new XmlTextNode("a & b"));
root.ToString(); // <e>a &amp; b</e>
```

## Best Practices

# Best Practices

Write text nodes as children of an element. Document-level character data is rejected by the writer.

## Patterns

# Patterns

Prefer `InnerText` on the parent element when the element has simple content. Use `XmlTextNode` in mixed content lists.

## Considerations

# Considerations

`WriteTo` calls `WriteStringValue` (escaped). Text nodes have no namespace. Null constructor argument becomes empty.
