## Summary

An ordered list of [XmlAttributeNode](/api-reference/CloudNimble/Text/Xml/Nodes/XmlAttributeNode) instances on an element.

## Usage

# Usage

`XmlElementNode.Attributes` is an `IList<XmlAttributeNode>` with name indexers.

```csharp
root.SetAttribute("a", "1");
root.Attributes["a"]!.Value; // 1
root.Attributes["a", ""] ;   // by local name + namespace
```

## Examples

# Examples

```csharp
root.Attributes.Insert(0, new XmlAttributeNode("id", "1"));
root.Attributes.RemoveAt(0);
```

## Best Practices

# Best Practices

Use `SetAttribute` for upsert. Use the list when you need order, insert, or remove.

## Patterns

# Patterns

Replace in place with the indexer setter. `Clear` detaches every attribute.

## Considerations

# Considerations

Adding an attribute that already has a parent throws. Indexers return null when the name is missing. The list is never read-only.
