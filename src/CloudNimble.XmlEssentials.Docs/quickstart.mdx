# Quickstart

```bash
dotnet add package XmlEssentials
```

Package id is `XmlEssentials`. Assembly is `CloudNimble.XmlEssentials`. Namespace is `CloudNimble.Text.Xml`.

```csharp
using CloudNimble.Text.Xml;

var xml = """
    <Person id="1">
      <Name>Ada</Name>
    </Person>
    """u8;

var reader = new Utf8XmlReader(xml);
while (reader.Read())
{
    if (reader.TokenType == XmlTokenType.StartElement
        && reader.LocalNameEquals("Name"u8))
    {
        reader.Read();
        Console.WriteLine(reader.GetString());
    }
}
```

Empty tags (`<Person id="1"/>`) are `StartElement` with `IsEmptyElement` true. There is no following `EndElement`.

Prefer `ValueSpan` and `TryGetInt32` / `TryGetBoolean` when you can stay in UTF-8. `GetString` allocates.

Write with `Utf8XmlWriter` over `IBufferWriter<byte>` or `Stream`:

```csharp
var buffer = new ArrayBufferWriter<byte>();
using (var writer = new Utf8XmlWriter(buffer, new XmlWriterOptions { OmitXmlDeclaration = true }))
{
    writer.WriteStartElement("Person");
    writer.WriteAttributeString("id", "1");
    writer.WriteElementString("Name", "Ada");
    writer.WriteEndElement();
}
```

`XmlSerializer` is not in this release. The reader and writer are the current public entry points.
