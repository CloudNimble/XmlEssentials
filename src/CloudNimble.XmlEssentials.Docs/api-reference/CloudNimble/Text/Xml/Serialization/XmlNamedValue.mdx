## Summary

Represents a value together with the name of the element it is written under. This class cannot be inherited.

## Remarks

A member that carries more than one `XmlElementAttribute`1` holds a choice of elements, and a
value is written under the element of its type. When two of the elements hold the same type, the type does
not say which element a value is. Declare the member as [XmlNamedValue](/api-reference/CloudNimble/Text/Xml/Serialization/XmlNamedValue), or as a collection of
it, and each value says which element it is by name.

[XmlNamedValue.Name](/api-reference/CloudNimble/Text/Xml/Serialization/XmlNamedValue#name) must be the name of one of the member's elements, and [XmlNamedValue.Value](/api-reference/CloudNimble/Text/Xml/Serialization/XmlNamedValue#value) must be of
           the type that element holds. A value that is [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) is written as an element marked
           `xsi:nil`.

## Examples

```csharp
public sealed class Contact
{
    [XmlElement<string>("Home")]
    [XmlElement<string>("Work")]
    public List<XmlNamedValue> Phones { get; set; } = [];
}

var contact = new Contact { Phones = { new XmlNamedValue("Work", "555-0100"), new XmlNamedValue("Home", "555-0199") } };
string xml = XmlSerializer.Serialize(contact);
// <Contact><Work>555-0100</Work><Home>555-0199</Home></Contact>
```
