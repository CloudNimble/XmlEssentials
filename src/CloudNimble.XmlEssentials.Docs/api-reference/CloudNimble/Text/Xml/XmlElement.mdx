## Usage

# Usage

`XmlElement` is a struct cursor into an `XmlDocument`, analogous to `JsonElement`. Read names, attributes, children, and typed values from the current node.

```csharp
using var document = XmlDocument.Parse("<e a=\"1\"><n>42</n></e>");
var root = document.RootElement;
var n = root.GetChild("n").GetInt32();
foreach (var attr in root.EnumerateAttributes())
{
    Console.WriteLine($"{attr.LocalName}={attr.GetString()}");
}
```

`GetRawXml` reconstructs this node. `CloneNode` copies it into a mutable `XmlNode` tree.

## Examples

# Examples

Namespaced lookup:

```csharp
using var document = XmlDocument.Parse("<r xmlns:p=\"urn:x\"><p:a>1</p:a></r>");
document.RootElement.GetChild("a", "urn:x").GetInt32(); // 1
```

Typed values use XSD 1.0 lexical forms (`true`/`false`/`1`/`0`, `INF`/`NaN`, round-trip dateTime, GUID, base64).

```csharp
using var document = XmlDocument.Parse("<e>true</e>");
document.RootElement.GetBoolean(); // true
```

## Best Practices

# Best Practices

- Keep the `XmlDocument` alive for the lifetime of any cursor.
- Prefer `TryGetChild` / `TryGetAttribute` on optional names.
- Use `ValueKind` or `TokenType` before calling typed getters on mixed content.
- Do not compare `XmlElement` instances from different documents; equality is document plus row index.

## Patterns

# Patterns

**Named child.** `TryGetChild(localName, out var child)` then `GetInt32` / `GetString`. Missing names return false; `GetChild` throws `XmlException`.

**Attributes.** `GetAttribute("id")` for a required attribute. `EnumerateAttributes` walks in document order, including `xmlns*` that the writer will skip on `WriteTo`.

**Write.** `WriteTo(writer)` or `GetRawXml()` for a fragment. `xmlns*` attributes are not written as attributes; `Utf8XmlWriter` redeclares namespaces from the element URI and prefix.

## Considerations

# Considerations

The default cursor (`default(XmlElement)`) has `ValueKind` `Undefined`. Any other member throws `InvalidOperationException`.

Empty elements are `XmlValueKind.EmptyElement` with `IsEmptyElement` true. `xsi:nil="true"` is `XmlValueKind.Nil` and `GetString` returns null.

Enumerators are nested types (`XmlElement.Enumerator`, `XmlElement.AttributeEnumerator`) to match `JsonElement`. `GetEnumerator` returns the same struct so `foreach` works.

`GetInnerText` concatenates descendant text and CDATA. Comments and PIs are omitted from inner text.
