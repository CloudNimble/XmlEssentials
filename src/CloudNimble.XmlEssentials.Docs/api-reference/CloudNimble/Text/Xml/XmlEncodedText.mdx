## Summary

Cached escaped UTF-8 for hot element and attribute names.

## Usage

# Usage

Cache a name once and pass it to `Utf8XmlWriter.WriteStartElement`:

```csharp
var root = XmlEncodedText.Encode("root");
writer.WriteStartElement(root);
writer.WriteEndElement();
```

`Encode` accepts `string`, `ReadOnlySpan<char>`, or UTF-8 `ReadOnlySpan<byte>`. `EncodedUtf8Bytes` is the cached name.

## Examples

# Examples

```csharp
var name = XmlEncodedText.Encode("Person"u8);
var copy = XmlEncodedText.Encode("Person");
name.Equals(copy); // true
name.ToString();   // "Person"
```

## Best Practices

# Best Practices

- Encode names once, not per element.
- Do not use this type for text values; it does not apply `&amp;` / `&lt;` escaping.
- Compare with `Equals` or `==`, not `ToString()`.

## Patterns

# Patterns

**Static cache.** Store `XmlEncodedText` in a `static readonly` field on the serializer or converter that writes that element name in a loop.

**UTF-8 literal.** `XmlEncodedText.Encode("id"u8)` avoids a UTF-16 transcode at cache-fill time.

## Considerations

# Considerations

`XmlEncodedText` stores UTF-8 name bytes. It does not escape markup; XML names are not escaped. Invalid names still fail at write time unless `SkipValidation` is set.

Equality is ordinal UTF-8 byte equality. The prefix is not part of this type; it is a local name (or other name token) only.
