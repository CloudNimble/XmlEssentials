## Summary

A mutable XML attribute.

## Usage

# Usage

```csharp
var attribute = new XmlAttributeNode("id", "1");
element.Attributes.Add(attribute);
attribute.Value = "2";
```

Prefixed attributes take `namespaceUri` and `prefix`. `WriteTo` must run while a start tag is open.

## Examples

# Examples

```csharp
var holder = new XmlElementNode("e");
holder.Attributes.Add(new XmlAttributeNode("a", "1", "urn:x", "p"));
holder.ToString(); // contains p:a="1"
```

## Best Practices

# Best Practices

Do not add `xmlns` / `xmlns:*` attributes unless you are mirroring an infoset; `WriteTo` skips them and the writer redeclares namespaces.

## Patterns

# Patterns

Prefer `XmlElementNode.SetAttribute` to add or replace by name. Use this type when you need a prefix or to move an attribute via clone.

## Considerations

# Considerations

`LocalName` rejects null or whitespace. `Prefix`, `NamespaceUri`, and `Value` coerce null to empty. `ValueKind` is `Attribute`.
