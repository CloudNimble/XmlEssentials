## Summary

Converts *T* to and from XML.

## Remarks

[XmlConverter`1.Read](/api-reference/CloudNimble/Text/Xml/Serialization/XmlConverter#read) is invoked with the reader on the start tag of that value.
The converter consumes through the matching end tag (or handles an empty element).

- `T` - The CLR type.
