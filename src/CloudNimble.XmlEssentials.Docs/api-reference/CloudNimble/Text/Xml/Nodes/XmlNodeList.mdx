## Usage

# Usage

`XmlElementNode.Children` is an `IList<XmlNode>` of mixed content.

```csharp
root.Children.Add(new XmlTextNode("hi"));
root.Children.Insert(0, new XmlCommentNode("c"));
```

## Examples

# Examples

```csharp
var child = root.Children[0];
root.Children.Remove(child);
child.Parent; // null
```

## Best Practices

# Best Practices

Clone a node (`DeepClone`) before attaching it to a second parent.

## Patterns

# Patterns

Walk with `foreach` or `XmlElementNode`’s `IEnumerable<XmlNode>`. Filter with `is XmlElementNode` when you want child elements only.

## Considerations

# Considerations

A node may belong to one list. `Add` / `Insert` / indexer set throw if `Parent` is already set. `Remove` returns false when the node is not in the list.
