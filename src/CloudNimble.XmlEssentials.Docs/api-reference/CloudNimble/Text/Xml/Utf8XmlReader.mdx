## Summary

A `ref struct` UTF-8 XML tokenizer analogous to `Utf8JsonReader`.

## Usage

Create a reader over UTF-8 bytes (a `u8` literal, a `byte[]`, a `ReadOnlySpan<byte>`, or a `ReadOnlySequence<byte>`) and call `Read` until it returns `false`. After each call, `TokenType` says what the reader is on.

```csharp
ReadOnlySpan<byte> xml = """
    <Order id="1042">
      <Item>Keyboard</Item>
      <Item>Mouse</Item>
      <Total>129.90</Total>
    </Order>
    """u8;

var reader = new Utf8XmlReader(xml);
while (reader.Read())
{
    if (reader.TokenType is not XmlTokenType.StartElement)
    {
        continue;
    }

    if (reader.LocalNameEquals("Order"u8))
    {
        while (reader.MoveToNextAttribute())
        {
            if (reader.LocalNameEquals("id"u8))
            {
                output.WriteLine($"Order {reader.GetInt32()}");
            }
        }

        reader.MoveToElement();
    }
    else if (reader.LocalNameEquals("Item"u8))
    {
        reader.Read();
        output.WriteLine($"Item: {reader.GetString()}");
    }
    else if (reader.LocalNameEquals("Total"u8))
    {
        reader.Read();
        output.WriteLine($"Total: {reader.GetDecimal()}");
    }
}
```

The members you use most:

| To | Use |
| --- | --- |
| Move to the next token | `Read` |
| Identify an element or attribute | `LocalNameEquals`, `NamespaceUriEquals`, `LocalNameSpan`, `PrefixSpan`, `NamespaceUriSpan` |
| Visit the attributes of a start tag | `MoveToNextAttribute`, `MoveToElement`, `AttributeCount` |
| Tell `<e/>` from `<e></e>` | `IsEmptyElement` |
| Read a value | `ValueSpan`, `GetString`, the `Get*` and `TryGet*` methods, `ValueTextEquals`, `CopyString` |
| Pass over an element | `Skip`, `TrySkip` |
| Read in blocks | The `isFinalBlock` constructors, `CurrentState`, `BytesConsumed` |

Pass an [`XmlReaderOptions`](/api-reference/CloudNimble/Text/Xml/XmlReaderOptions) to the constructor to leave out comments and the white space between elements, to read a fragment, or to change a limit. By default the reader reports both, so that a document can be written back unchanged. The loop above isn't affected, because it acts only on start tags.

For a walk through every feature, see [How to read XML with Utf8XmlReader](/guides/use-utf8xmlreader).

## Remarks

Empty elements are reported as [XmlTokenType.StartElement](/api-reference/CloudNimble/Text/Xml/XmlTokenType) with
[Utf8XmlReader.IsEmptyElement](/api-reference/CloudNimble/Text/Xml/Utf8XmlReader#isemptyelement) true. The reader does not synthesize an
[XmlTokenType.EndElement](/api-reference/CloudNimble/Text/Xml/XmlTokenType) token. Callers must check
[Utf8XmlReader.IsEmptyElement](/api-reference/CloudNimble/Text/Xml/Utf8XmlReader#isemptyelement) before expecting a matching end tag.
xmlns attributes bind before the element name is resolved. Unprefixed attributes
are in no namespace; unprefixed elements use the default xmlns.
The XML declaration, when present, must be the first token in the document (after an optional BOM).

### Read typed values

The `Get*` methods parse a value in place and throw an `XmlException` when it isn't valid for the type. The `TryGet*` methods return `false` instead.

```csharp
ReadOnlySpan<byte> xml = """
    <Order id="1042" rush="true">
      <Placed>2026-03-14T09:30:00+01:00</Placed>
      <Total>129.90</Total>
      <Quantity>three</Quantity>
    </Order>
    """u8;

var reader = new Utf8XmlReader(xml);
while (reader.Read())
{
    if (reader.TokenType is not XmlTokenType.StartElement)
    {
        continue;
    }

    if (reader.LocalNameEquals("Order"u8))
    {
        while (reader.MoveToNextAttribute())
        {
            if (reader.LocalNameEquals("id"u8))
            {
                output.WriteLine($"id: {reader.GetInt32()}");
            }
            else if (reader.LocalNameEquals("rush"u8))
            {
                output.WriteLine($"rush: {reader.GetBoolean()}");
            }
        }
    }
    else if (reader.LocalNameEquals("Placed"u8))
    {
        reader.Read();
        output.WriteLine($"Placed: {reader.GetDateTimeOffset():O}");
    }
    else if (reader.LocalNameEquals("Total"u8))
    {
        reader.Read();
        output.WriteLine($"Total: {reader.GetDecimal().ToString(CultureInfo.InvariantCulture)}");
    }
    else if (reader.LocalNameEquals("Quantity"u8))
    {
        reader.Read();
        if (reader.TryGetInt32(out var quantity))
        {
            output.WriteLine($"Quantity: {quantity}");
        }
        else
        {
            output.WriteLine($"Quantity is not a number: {reader.GetString()}");
        }
    }
}
```

```text
id: 1042
rush: True
Placed: 2026-03-14T09:30:00.0000000+01:00
Total: 129.90
Quantity is not a number: three
```

### Read names with their namespaces

```csharp
ReadOnlySpan<byte> xml = """
    <feed xmlns="http://www.w3.org/2005/Atom" xmlns:dc="http://purl.org/dc/elements/1.1/">
      <title lang="en">Orders</title>
      <dc:creator>Ada</dc:creator>
    </feed>
    """u8;

var reader = new Utf8XmlReader(xml);
while (reader.Read())
{
    if (reader.TokenType is not XmlTokenType.StartElement)
    {
        continue;
    }

    output.WriteLine($"Element prefix='{Encoding.UTF8.GetString(reader.PrefixSpan)}' local='{Encoding.UTF8.GetString(reader.LocalNameSpan)}' namespace='{Encoding.UTF8.GetString(reader.NamespaceUriSpan)}'");
    if (reader.LocalNameEquals("creator"u8) && reader.NamespaceUriEquals("http://purl.org/dc/elements/1.1/"u8))
    {
        output.WriteLine("  This is the Dublin Core creator element.");
    }

    while (reader.MoveToNextAttribute())
    {
        output.WriteLine($"  Attribute prefix='{Encoding.UTF8.GetString(reader.PrefixSpan)}' local='{Encoding.UTF8.GetString(reader.LocalNameSpan)}' namespace='{Encoding.UTF8.GetString(reader.NamespaceUriSpan)}'");
    }
}
```

  Attribute prefix='xmlns' local='dc' namespace='http://www.w3.org/2000/xmlns/'
Element prefix='' local='title' namespace='http://www.w3.org/2005/Atom'
  Attribute prefix='' local='lang' namespace=''
Element prefix='dc' local='creator' namespace='http://purl.org/dc/elements/1.1/'

### Skip an element

```csharp
ReadOnlySpan<byte> xml = """
    <Order>
      <Customer>
        <Name>Ada</Name>
        <Address><City>London</City></Address>
      </Customer>
      <Total>129.90</Total>
    </Order>
    """u8;

var reader = new Utf8XmlReader(xml);
while (reader.Read())
{
    if (reader.TokenType is not XmlTokenType.StartElement)
    {
        continue;
    }

    if (reader.LocalNameEquals("Customer"u8))
    {
        reader.Skip();
        output.WriteLine($"Skipped Customer. Now on {reader.TokenType} {Encoding.UTF8.GetString(reader.LocalNameSpan)} at depth {reader.CurrentDepth}.");
    }
    else
    {
        output.WriteLine($"Read {Encoding.UTF8.GetString(reader.LocalNameSpan)}");
    }
}
```

```text
Read Order
Skipped Customer. Now on EndElement Customer at depth 1.
Read Total
```

## Best Practices

- **Compare names and values as UTF-8.** `reader.LocalNameEquals("Item"u8)` and `reader.ValueTextEquals("yes"u8)` compare bytes with bytes. `GetString()` followed by `==` creates a string for every comparison.
- **Match on the namespace URI and the local name, not on the prefix.** The producer of a document is free to choose any prefix.
- **Check `IsEmptyElement` on every start tag.** An empty element has no `EndElement` token, so code that counts depth or waits for an end tag has to know.
- **Read a value only on a token that has one.** Use the value members on `Text`, `CData`, `Attribute`, `Comment`, and `ProcessingInstruction` tokens.
- **Use `TryGet*` when a bad value is something you expect.** A `Get*` method throws an `XmlException` when a value isn't valid, which fits values that must be right.
- **Copy what you keep.** A span from the reader is valid until the reader moves.
- **Set `CommentHandling` to `Skip` and `WhitespaceHandling` to `Insignificant` in a loop that only wants data.** By default the reader reports comments and the white space between elements, so that a document can be written back unchanged.
- **Pass the reader with `ref`** to a helper method that advances it.
- **Give the reader a scratch buffer on a hot path.** With one that's large enough for the document, reading allocates nothing.
- **Take `CurrentState` once per block.** It copies the open element names and namespace bindings, so it allocates.

## Patterns

These are the shapes that code using the reader takes most often.

### Token loop

`while (reader.Read())` with a `switch` on `TokenType` is the basic shape, as with `Utf8JsonReader`. Handle `StartElement` and check `IsEmptyElement` before you expect content or an end tag.

### Attribute walk

On a start tag, call `MoveToNextAttribute` until it returns `false`. While the reader is on an attribute, `TokenType` is `Attribute` and the name and value members describe the attribute. Namespace declarations are part of the walk. `MoveToElement` returns to the start tag, and `Read` continues after the start tag whether or not you call it.

### Element with a value

After a start tag that you know holds text, call `Read` once and use a `Get*` or `TryGet*` method. For an element that can be empty, check that the token is `Text` or `CData` first.

### Look ahead

Copy the reader (`var lookahead = reader;`), read ahead with the copy inside the current element, and then drop the copy or carry on with it. A copy shares working memory with the original, so don't advance both in turn.

### Read in blocks

Construct a reader for each block with `isFinalBlock` and the state from the previous reader. When `Read` returns `false`, save `CurrentState`, keep the bytes after `BytesConsumed`, and add more data. The complete loop is in the example for [`XmlReaderState`](/api-reference/CloudNimble/Text/Xml/XmlReaderState).

### Custom converter

`XmlConverter<T>.Read` receives the reader by reference, positioned on the value to convert. See [Custom converters](/guides/custom-converters).

## Considerations

Know the following before you build on the reader.

### It's a ref struct

A reader can't be stored in a field of a class, captured by a lambda, or used across an `await` or a `yield return`. Passing it by value copies it. It isn't thread safe.

### Lifetime of spans

`ValueSpan`, `LocalNameSpan`, `PrefixSpan`, and `NamespaceUriSpan` point into your input, or into a buffer that the reader reuses for the next decoded value. They're valid until the reader moves. On a start tag or an end tag, `ValueSpan` isn't cleared and can hold the value of an earlier token.

### Allocation

Reading tokens, comparing names, and parsing typed values don't allocate. `GetString`, `GetComment`, and `GetBytesFromBase64` return new objects. The reader allocates working memory, once per reader, when a value has to be decoded, when a start tag has more than eight attributes, when more than eight namespace declarations are in scope, or when elements nest more than eight deep. The constructors that take a `scratch` buffer use that buffer first. A sequence of more than one segment is copied into one array before it's read, and `CurrentState` allocates.

### What it checks

The reader checks that the document is well formed as it reads, including names, characters, matching end tags, duplicate attributes, and namespace declarations. It doesn't validate against a DTD or a schema. An error is thrown when the reader reaches it, which can be after your code has handled the tokens before it.

### What it rejects

A document type declaration, an encoding other than UTF-8, and any entity other than the five predefined ones throw an `XmlException`. See [XML conformance](/guides/xml-conformance).

### Differences from Utf8JsonReader

- An empty element is one token with `IsEmptyElement` set. There's no end token for it.
- Attributes aren't tokens in the `Read` sequence. You visit them with `MoveToNextAttribute`.
- `HasValueSequence` is always `false` and `ValueSequence` is always empty. The value is always in `ValueSpan`.
- A copy of a reader shares working memory with the original.
- `XmlReaderState` holds the open elements and namespace bindings, so taking it allocates.

### Differences from System.Xml.XmlReader

- The input is UTF-8 bytes in memory, not a stream or a `TextReader`, and there's no asynchronous `Read`.
- DTDs are always rejected, and there's no validation, no entity resolution, and no `XmlResolver`.
- Names and values are spans of bytes. Strings are created only when you ask for one.
- The defaults are alike: both readers report comments and white space between elements unless you turn them off.

#### Remarks

A reader needs memory of its own in four cases: a value that holds a character or entity reference,
or a line end other than LF, is decoded into a buffer; a start tag with more than eight attributes
needs a larger attribute table; so do more than eight namespace declarations in scope; and so do
elements nested more than eight deep. Without *scratch* each of those is an array
allocated for this reader. With it, the reader takes the memory from *scratch*
and allocates only once that is used up, so a buffer of any size is safe and a larger one saves more.

Copies of the reader share the buffer, as they share the arrays a reader without one allocates.
A copy may look ahead within the element the original is on and then be dropped, or the copy
may be the one that carries on. Do not advance two copies in turn, and do not go back to the
original once a copy has read past the end of the element the original is on.
