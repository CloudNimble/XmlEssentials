## Usage

# Usage

```csharp
root.Add(new XmlProcessingInstructionNode("pi", "data"));
```

`Target` is required. `Data` may be null.

## Examples

# Examples

```csharp
var root = new XmlElementNode("e");
root.Add(new XmlProcessingInstructionNode("pi", "d"));
root.ToString(); // contains <?pi d?>
```

## Best Practices

# Best Practices

Do not use target `xml` (case-insensitive); that is the XML declaration, not a PI.

## Patterns

# Patterns

Document-level PIs belong on `XmlDocument` (prolog/epilog). Child PIs belong in `XmlElementNode.Children`.

## Considerations

# Considerations

The XML declaration is not a PI. Immutable documents store it as `XmlDeclarationInfo`. Prolog PIs on `XmlDocument` round-trip via `WriteTo` and are not children of `RootElement`. `XmlNode.Parse` discards them.
