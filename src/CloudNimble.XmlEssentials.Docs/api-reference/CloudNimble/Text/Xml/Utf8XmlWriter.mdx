## Usage

# Usage

Create the writer over an `IBufferWriter<byte>` or a `Stream`. Call `WriteStartElement` / `WriteEndElement` (or the `WriteElement*` helpers) and dispose the writer to flush.

```csharp
var buffer = new ArrayBufferWriter<byte>();
using (var writer = new Utf8XmlWriter(buffer, new XmlWriterOptions { OmitXmlDeclaration = true }))
{
    writer.WriteStartElement("root");
    writer.WriteAttributeString("id", "1");
    writer.WriteEmptyElement("flag");
    writer.WriteElementNumber("n", 42);
    writer.WriteEndElement();
}
```

Pass `new XmlWriterOptions { Indented = true }` for pretty-print. A max-* of `0` means the DoS table default (depth 64, 1000 attributes, 1024-byte names).

## Examples

# Examples

Empty vs full end:

```csharp
writer.WriteEmptyElement("e");               // <e/>

writer.WriteStartElement("e");
writer.WriteFullEndElement();                // <e></e>
```

Attributes on an empty element still use the start/end pair:

```csharp
writer.WriteStartElement("e");
writer.WriteAttributeString("id", "1");
writer.WriteEndElement();                    // <e id="1"/>
```

Namespaces and nil:

```csharp
writer.WriteEmptyElement("p", "e", "urn:x"); // <p:e xmlns:p="urn:x"/>
writer.WriteNilElement("n");                 // xmlns:xsi plus xsi:nil="true"
```

Typed values use XSD 1.0 lexical forms (`true`/`false`, `INF`/`NaN`, `yyyy-MM-ddTHH:mm:ss`, `PT1H`).

## Best Practices

# Best Practices

- Construct options with `new XmlWriterOptions()`. `default(XmlWriterOptions)` leaves `IndentCharacter` as NUL and `NewLine` as null; the writer substitutes space and `Environment.NewLine`.
- Keep payloads in UTF-8 (`u8` literals, `byte[]`). Cache repeated names with `XmlEncodedText.Encode`.
- Set `MaxDepth`, `MaxAttributeCount`, and `MaxNameByteCount` on untrusted object graphs.
- Call `WriteEndElement` for every start tag. Do not rely on `Dispose` to close elements; it throws instead.
- Use `OmitXmlDeclaration = true` for fragments. Write the declaration explicitly only when it must be the first output.

## Patterns

# Patterns

**Element pair.** `WriteStartElement`, attributes while the start tag is open, then content or `WriteEndElement`.

**Helpers.** `WriteEmptyElement` writes `<e/>`. `WriteNilElement` adds `xsi:nil="true"`. `WriteElementString`, `WriteElementNumber`, `WriteElementBoolean`, and `WriteElementBase64String` write a complete child with a value.

**Fragments.** `Reset` starts a new document on the same destination. `BytesCommitted` returns to 0. One BOM per writer lifetime.

**Raw inject.** `WriteRawValue` copies bytes after closing the start tag. Use `skipInputValidation: true` only for trusted markup.

**Streaming.** Prefer `ReadOnlySpan<byte>` and `XmlEncodedText` for hot names. `WriteStringValueSegment` / `WriteBase64StringSegment` append to the current value.

## Considerations

# Considerations

`Utf8XmlWriter` is a class, not a `ref struct`. Dispose flushes. If `SkipValidation` is false and elements are still open, `Dispose` throws `XmlException`.

Empty elements use `/>` from `WriteEndElement` when the start tag has no content. `WriteFullEndElement` always writes `</name>`.

Unprefixed elements in a namespace auto-declare `xmlns`. Prefixed names auto-declare `xmlns:prefix` when that URI is not in scope. Unprefixed attributes are in no namespace; a namespaced attribute without a prefix gets `ns1`, `ns2`, ….

Text escaping: `&` and `<` always, and `>` only as part of `]]>`. Attributes are double-quoted; `"` is escaped. CDATA containing `]]>` throws. Comments containing `--` or ending in `-` throw.

In XML 1.1, RestrictedChar in values is written as a hexadecimal numeric character reference. `EmitByteOrderMark` is false by default and emits `EF BB BF` once per writer lifetime.
