## Summary

A namespace-qualified XML name: local name, namespace URI, and optional prefix.

## Usage

An `XmlName` is a qualified XML name: a local name, a namespace URI, and an optional prefix. The library uses it wherever a name has to carry its namespace, for example `XmlTypeInfo.RootName`, `XmlPropertyInfo.Name`, and the keys of `XmlExtensionData.Attributes`.

Create a name with the local name alone, or add the namespace URI and the prefix:

```csharp
var written = new XmlName("Invoice", "urn:example:billing", "b");
var expected = new XmlName("Invoice", "urn:example:billing");
var unqualified = new XmlName("Invoice");
```

Two names are equal when their local names and namespace URIs are equal. The prefix is kept so that a name can be written the way it was read, and it plays no part in equality or in hash codes.

## Remarks

Equality is the ordinal combination of [XmlName.LocalName](/api-reference/CloudNimble/Text/Xml/XmlName#localname) and [XmlName.NamespaceUri](/api-reference/CloudNimble/Text/Xml/XmlName#namespaceuri).
[XmlName.Prefix](/api-reference/CloudNimble/Text/Xml/XmlName#prefix) is serialization sugar and is not significant for equality or mapping.

## Examples

### Compare and print names

`ToString` returns `prefix:local` when the name has a prefix, `{uri}local` when it has a namespace and no prefix, and the local name otherwise.

```csharp
var written = new XmlName("Invoice", "urn:example:billing", "b");
var expected = new XmlName("Invoice", "urn:example:billing");
var unqualified = new XmlName("Invoice");

output.WriteLine(written);
output.WriteLine(expected);
output.WriteLine(unqualified);
output.WriteLine(written == expected);
output.WriteLine(written == unqualified);
```

The code produces the following output:

```text
b:Invoice
{urn:example:billing}Invoice
Invoice
True
False
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/14_Namespaces.cs)

## Considerations

- `XmlName` is a `readonly struct` that holds three string references. Copying it is cheap, and creating one allocates nothing beyond the strings you pass in.
- The constructor checks only that the local name isn't `null`, empty, or white space. It doesn't check that the parts are valid XML names.
- A `null` namespace URI or prefix becomes an empty string, so `NamespaceUri` and `Prefix` are never `null`.
- Comparison is ordinal. Namespace URIs are compared character by character, as the Namespaces in XML recommendation requires, so `urn:Example` and `urn:example` are different namespaces.
- The output of `ToString` is for display. The `{uri}local` form is not XML syntax.
- `default(XmlName)` has a `null` local name. Don't use it as a name.
