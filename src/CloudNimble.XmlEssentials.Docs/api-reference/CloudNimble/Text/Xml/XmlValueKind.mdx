## Usage

# Usage

`XmlValueKind` discriminates an `XmlElement` cursor or a mutable `XmlNode`.

```csharp
using var document = XmlDocument.Parse("<e>x</e>");
foreach (var child in document.RootElement.EnumerateChildren())
{
    if (child.ValueKind is XmlValueKind.Text)
    {
        Console.WriteLine(child.GetString());
    }
}
```

## Examples

# Examples

`TokenType` maps element kinds to `StartElement`, attributes to `Attribute`, and leaves to their token. Unknown kinds map to `None`.

## Best Practices

# Best Practices

Do not assume every child is an element. Check `ValueKind` is `Element`, `EmptyElement`, or `Nil` before `GetChild`-style navigation on a cursor you enumerated.

## Patterns

# Patterns

Switch on `ValueKind` before calling typed getters. Mixed content can be text, CDATA, comments, PIs, and child elements in one list.

## Considerations

# Considerations

`Undefined` is the default cursor. `Document` is reserved for the document node (not exposed as `XmlElement`). `EmptyElement` is `<e/>`. `Nil` is `xsi:nil="true"`. `XmlDeclaration` is used by `XmlDeclarationNode` only; immutable documents store `XmlDeclarationInfo` instead.
