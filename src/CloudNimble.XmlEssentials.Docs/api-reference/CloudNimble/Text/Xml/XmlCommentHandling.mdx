## Usage

# Usage

Set `XmlReaderOptions.CommentHandling` to control `<!-- ... -->` tokens:

- `Skip` — consume comments and do not report them. This is the `new XmlReaderOptions()` default.
- `Allow` — report `XmlTokenType.Comment`; read the payload with `GetComment()`.
- `Disallow` — throw `XmlException`. This is the enum's zero value.

## Examples

# Examples

```csharp
var xml = "<!-- note --><e/>"u8;

var skip = new Utf8XmlReader(xml); // constructor default: Skip
skip.Read(); // StartElement e

var allow = new Utf8XmlReader(xml, new XmlReaderOptions
{
    CommentHandling = XmlCommentHandling.Allow,
});
allow.Read(); // Comment
Console.WriteLine(allow.GetComment()); // " note "
```

## Best Practices

# Best Practices

Leave the constructor default (`Skip`) unless you are round-tripping comments or validating that none exist.

Use `Disallow` on untrusted input when comments are out of contract (for example a machine-to-machine schema with no annotations).

## Patterns

# Patterns

**Ignore.** `new Utf8XmlReader(utf8)` — comments vanish from the token stream.

**Preserve.** `CommentHandling = Allow`, then handle `XmlTokenType.Comment` in the loop.

**Forbid.** `CommentHandling = Disallow` so a comment is `XmlException` instead of silent skip.

## Considerations

# Considerations

`Disallow = 0`. A defaulted `XmlReaderOptions` struct (including `Utf8XmlReader`'s optional-parameter `default`) is Disallow. `new XmlReaderOptions()` sets `Skip`.

Comments containing `--` are always well-formedness errors, regardless of this setting.

`MaxCommentByteCount` applies when a comment is parsed, including when it is skipped.
