## Summary

Options for [Utf8XmlReader](/api-reference/CloudNimble/Text/Xml/Utf8XmlReader).

## Usage

# Usage

Pass a constructed options struct into `Utf8XmlReader`:

```csharp
var options = new XmlReaderOptions
{
    MaxDepth = 32,
    CommentHandling = XmlCommentHandling.Allow,
};
var reader = new Utf8XmlReader(utf8, options);
```

Omit the argument for defaults: comments skipped, insignificant whitespace between elements skipped, a single root required, every max-* at `0` (table defaults).

## Remarks

A max-* of 0 means the default from the DoS table, except [XmlReaderOptions.MaxDocumentByteCount](/api-reference/CloudNimble/Text/Xml/XmlReaderOptions#maxdocumentbytecount)
which stays unbounded. Construct with `new XmlReaderOptions()` so
[XmlReaderOptions.CommentHandling](/api-reference/CloudNimble/Text/Xml/XmlReaderOptions#commenthandling) defaults to [XmlCommentHandling.Skip](/api-reference/CloudNimble/Text/Xml/XmlCommentHandling).

## Examples

# Examples

Strict comments and no insignificant whitespace:

```csharp
var options = new XmlReaderOptions
{
    CommentHandling = XmlCommentHandling.Disallow,
    WhitespaceHandling = XmlWhitespaceHandling.None,
};
```

A document fragment with two roots:

```csharp
var options = new XmlReaderOptions { AllowMultipleRoots = true };
var reader = new Utf8XmlReader("<a/><b/>"u8, options);
```

## Best Practices

# Best Practices

- Always write `new XmlReaderOptions()` when you need defaults, including when you set only `MaxDepth`.
- Cap `MaxDepth` and `MaxNameByteCount` on untrusted input. Billion-laughs-style DTDs are already rejected; deep trees and huge names are not.
- Leave `MaxDocumentByteCount` at 0 unless an upper layer (document parse, deserialize) will apply it.
- Match comment and whitespace policy to the producer. SOAP and XHTML often need `CommentHandling.Skip` (the constructor default).

## Patterns

# Patterns

**Trusted payload.** `new Utf8XmlReader(utf8)` with no options object.

**Untrusted payload.** `new XmlReaderOptions { MaxDepth = 32, MaxTextByteCount = 1_048_576 }` and the other caps you care about.

**Fragments.** `AllowMultipleRoots = true` for SOAP-style concatenations or test snippets without a wrapper element.

## Considerations

# Considerations

`XmlReaderOptions` is a struct. `new XmlReaderOptions()` runs the constructor and sets `CommentHandling` to `Skip`. `default(XmlReaderOptions)` leaves `CommentHandling` at `Disallow` (enum zero). Prefer `new`.

A max-* of `0` means “use the table default”:

| Property | When 0 |
| --- | --- |
| `MaxDepth` | 64 |
| `MaxAttributeCount` | 1000 |
| `MaxNameByteCount` | 1024 |
| `MaxCommentByteCount` | 1,048,576 |
| `MaxTextByteCount` | 16,777,216 |
| `MaxDocumentByteCount` | unbounded (stays 0) |

`MaxDocumentByteCount` is stored on the options but is not enforced by `Utf8XmlReader` in this release.
