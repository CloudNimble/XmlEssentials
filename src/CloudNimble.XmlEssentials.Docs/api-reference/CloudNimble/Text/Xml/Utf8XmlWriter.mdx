## Summary

A UTF-8 XML writer analogous to `Utf8JsonWriter`.

## Usage

Create a writer over an `IBufferWriter<byte>` or a `Stream`, write the document with one call per start tag, attribute, value, and end tag, and dispose the writer to flush it.

```csharp
var buffer = new ArrayBufferWriter<byte>();
var options = new XmlWriterOptions { Indented = true, NewLine = "\n" };

using (var writer = new Utf8XmlWriter(buffer, options))
{
    writer.WriteStartElement("Order");
    writer.WriteAttributeString("id", "1042");

    writer.WriteStartElement("Customer");
    writer.WriteStringValue("Ada Lovelace");
    writer.WriteEndElement();

    writer.WriteStartElement("Total");
    writer.WriteAttributeString("currency", "EUR");
    writer.WriteNumberValue(129.90m);
    writer.WriteEndElement();

    writer.WriteStartElement("Notes");
    writer.WriteEndElement();

    writer.WriteEndElement();
}

output.WriteLine(Encoding.UTF8.GetString(buffer.WrittenSpan));
```

```xml
<?xml version="1.0" encoding="utf-8"?>
<Order id="1042">
  <Customer>Ada Lovelace</Customer>
  <Total currency="EUR">129.90</Total>
  <Notes/>
</Order>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/23_WriteElementsAndValues.cs)

The members you use most:

| To | Use |
| --- | --- |
| Open and close an element | `WriteStartElement`, `WriteEndElement`, `WriteFullEndElement` |
| Write an attribute | `WriteAttributeString`, `WriteAttributeNumber`, or `WriteStartAttribute` and `WriteEndAttribute` around a value |
| Write a value | `WriteStringValue`, `WriteNumberValue`, `WriteBooleanValue`, `WriteBase64StringValue` |
| Write a complete element | `WriteElementString`, `WriteElementNumber`, `WriteElementBoolean`, `WriteElementBase64String`, `WriteEmptyElement`, `WriteNilElement` |
| Declare a namespace yourself | `WriteNamespaceDeclaration`, `WriteDefaultNamespace` |
| Write other markup | `WriteComment`, `WriteCData`, `WriteProcessingInstruction`, `WriteXmlDeclaration`, `WriteRawValue` |
| Send output on its way | `Flush`, `FlushAsync`, `Dispose`, `DisposeAsync` |
| Write another document | `Reset` |

Names and values can be a `string`, a `ReadOnlySpan<char>`, or UTF-8 in a `ReadOnlySpan<byte>`. Pass an [`XmlWriterOptions`](/api-reference/CloudNimble/Text/Xml/XmlWriterOptions) to the constructor to indent, to leave out the declaration, or to change a limit.

For a walk through every feature, see [How to write XML with Utf8XmlWriter](/guides/use-utf8xmlwriter).

## Remarks

Destinations are [IBufferWriter`1](https://learn.microsoft.com/dotnet/api/system.buffers.ibufferwriter-1) or [Stream](https://learn.microsoft.com/dotnet/api/system.io.stream). Names and values are UTF-8.
A max-* of 0 on [XmlWriterOptions](/api-reference/CloudNimble/Text/Xml/XmlWriterOptions) uses the DoS table default. Dispose flushes and throws
when elements are still open unless [XmlWriterOptions.SkipValidation](/api-reference/CloudNimble/Text/Xml/XmlWriterOptions#skipvalidation) is true.

### Write complete elements

```csharp
var buffer = new ArrayBufferWriter<byte>();
var options = new XmlWriterOptions { Indented = true, NewLine = "\n", OmitXmlDeclaration = true };

using (var writer = new Utf8XmlWriter(buffer, options))
{
    writer.WriteStartElement("Order");
    writer.WriteElementString("Item", "Keyboard");
    writer.WriteElementNumber("Quantity", 2);
    writer.WriteElementNumber("Total", 129.90m);
    writer.WriteElementBoolean("Rush", true);
    writer.WriteElementString("Placed", new DateTime(2026, 3, 14, 9, 30, 0, DateTimeKind.Utc));
    writer.WriteElementBase64String("Signature", [0x58, 0x4D, 0x4C, 0x21]);
    writer.WriteElementString("Comment", null);
    writer.WriteEmptyElement("Gift");
    writer.WriteNilElement("Discount");

    writer.WriteStartElement("Notes");
    writer.WriteFullEndElement();

    writer.WriteEndElement();
}

output.WriteLine(Encoding.UTF8.GetString(buffer.WrittenSpan));
```

```xml
<Order>
  <Item>Keyboard</Item>
  <Quantity>2</Quantity>
  <Total>129.90</Total>
  <Rush>true</Rush>
  <Placed>2026-03-14T09:30:00Z</Placed>
  <Signature>WE1MIQ==</Signature>
  <Comment/>
  <Gift/>
  <Discount xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:nil="true"/>
  <Notes></Notes>
</Order>
```

### Write namespaces

Pass the namespace URI, and the writer chooses or declares the prefix.

```csharp
const string atom = "http://www.w3.org/2005/Atom";
const string dublinCore = "http://purl.org/dc/elements/1.1/";
const string shop = "urn:example:shop";

var buffer = new ArrayBufferWriter<byte>();
var options = new XmlWriterOptions { Indented = true, NewLine = "\n", OmitXmlDeclaration = true };

using (var writer = new Utf8XmlWriter(buffer, options))
{
    // The writer declares the default namespace because nothing in scope is bound to it.
    writer.WriteStartElement("feed", atom);

    // Declare a prefix on the root so that every descendant can use it.
    writer.WriteNamespaceDeclaration("dc", dublinCore);

    // The namespace is the default one in scope, so the element needs no prefix.
    writer.WriteElementString("title", atom, "Orders");

    // The namespace is bound to dc, so the writer uses that prefix.
    writer.WriteElementString("creator", dublinCore, "Ada");

    // A prefix and a namespace that are not in scope: the writer declares them on this element.
    writer.WriteStartElement("s", "order", shop);
    writer.WriteAttributeString("s", "id", shop, "1042");
    writer.WriteEndElement();

    // An attribute in a namespace that has no prefix in scope gets a generated one.
    writer.WriteStartElement("entry", atom);
    writer.WriteAttributeString("priority", shop, "high");
    writer.WriteAttributeString("lang", "en");
    writer.WriteEndElement();

    writer.WriteEndElement();
}

output.WriteLine(Encoding.UTF8.GetString(buffer.WrittenSpan));
```

```xml
<feed xmlns="http://www.w3.org/2005/Atom" xmlns:dc="http://purl.org/dc/elements/1.1/">
  <title>Orders</title>
  <dc:creator>Ada</dc:creator>
  <s:order xmlns:s="urn:example:shop" s:id="1042"/>
  <entry xmlns:ns1="urn:example:shop" ns1:priority="high" lang="en"/>
</feed>
```

### Reuse one writer for several documents

```csharp
var buffer = new ArrayBufferWriter<byte>();
using var writer = new Utf8XmlWriter(buffer, new XmlWriterOptions { OmitXmlDeclaration = true });

string[] items = ["Keyboard", "Mouse", "Monitor"];
foreach (var item in items)
{
    writer.WriteStartElement("Item");
    writer.WriteStringValue(item);
    writer.WriteEndElement();
    writer.Flush();

    output.WriteLine($"{Encoding.UTF8.GetString(buffer.WrittenSpan)} ({writer.BytesCommitted} bytes)");

    buffer.ResetWrittenCount();
    writer.Reset();
}

var other = new ArrayBufferWriter<byte>();
writer.Reset(other);
writer.WriteEmptyElement("Done");
writer.Flush();
output.WriteLine($"Second buffer: {Encoding.UTF8.GetString(other.WrittenSpan)}");
```

```text
<Item>Keyboard</Item> (21 bytes)
<Item>Mouse</Item> (18 bytes)
<Item>Monitor</Item> (20 bytes)
Second buffer: <Done/>
```

## Best Practices

- **Dispose the writer, or call `Flush`, before you read the output.** Until then, bytes are pending and the buffer or stream doesn't have them.
- **End every element yourself.** `Dispose` throws an `XmlException` when an element is still open. It doesn't close elements for you.
- **Use the `WriteElement*` methods for elements that hold one value.** One call replaces three.
- **Pass `u8` literals for names that are fixed.** `writer.WriteStartElement("Order"u8)` skips the conversion from UTF-16. For a name computed once at run time, keep an `XmlEncodedText`.
- **Declare the prefixes you use often on the root element** with `WriteNamespaceDeclaration`. Otherwise the writer declares a prefix again on every element that needs it and isn't inside one that has it.
- **Reuse a writer with `Reset` on a hot path.** A reused writer allocates nothing per document.
- **Set `NewLine` when the bytes matter.** The default depends on the operating system.
- **Write binary data with one `WriteBase64StringValue` call,** not in segments.
- **Use `WriteRawValue` only for XML that your own code produced.** The input isn't checked or escaped.
- **Discard the output when the writer throws.** Part of the document may already be committed.

## Patterns

These are the shapes that code using the writer takes most often.

### Element with attributes and content

Call `WriteStartElement`, then the attributes and namespace declarations, then the content, then `WriteEndElement`. The start tag closes when you write the first content, and attributes aren't accepted after that.

### Leaf element

`WriteElementString`, `WriteElementNumber`, `WriteElementBoolean`, and `WriteElementBase64String` write a start tag, a value, and an end tag in one call. `WriteEmptyElement` writes `<e/>`, and `WriteNilElement` writes an empty element with `xsi:nil="true"`.

### Attribute with a typed value

For a type that `WriteAttributeString` and `WriteAttributeNumber` don't take, open the attribute with `WriteStartAttribute`, call a value method such as `WriteBooleanValue` or `WriteStringValue(DateTimeOffset)`, and close it with `WriteEndAttribute`.

### One writer, many documents

Create the writer once, and after each document call `Flush` and then `Reset`. Use `Reset(IBufferWriter<byte>)` or `Reset(Stream)` to send the next document somewhere else.

### Stream with asynchronous flushes

Write with the synchronous methods, which only fill the writer's buffer, and call `await writer.FlushAsync()` at points where a batch is complete. Dispose with `await using`.

### Copy a parsed document

`XmlDocument.WriteTo` and `XmlElement.WriteTo` write a parsed document, or one element of it, into a writer. See [How to use XmlDocument](/guides/use-xmldocument).

### Custom converter

`XmlConverter<T>.Write` receives the writer, positioned where the value goes. See [Custom converters](/guides/custom-converters).

## Considerations

Know the following before you build on the writer.

### Output and buffering

The output is always UTF-8. With an `IBufferWriter<byte>`, the writer writes into memory it gets from the buffer writer and commits it on `Flush`, on `Dispose`, and when it needs more room. With a `Stream`, it fills a buffer rented from the array pool, which starts at 16 KB, and writes to the stream on `Flush`, on `Dispose`, and when the buffer fills. Disposing the writer doesn't close the stream.

### Dispose and open elements

`Dispose` and `DisposeAsync` flush. If an element is still open and `SkipValidation` is `false`, they throw an `XmlException` and don't flush. In a `using` statement, that exception replaces an exception that was already on its way out, so the message you catch can be `The document has unclosed elements.` when the real cause came earlier.

### Thread safety

A writer isn't thread safe. Use each instance from one thread at a time. See [Thread safety](/guides/thread-safety).

### Allocation

A writer that's reused with `Reset` allocates nothing per document. In the library's benchmarks, a small document takes 55 ns and 0 B with a reused writer, against 325 ns and 7,328 B for `System.Xml.XmlWriter`. See [Benchmarks](/benchmarks).

### Namespaces

The writer tracks the namespaces in scope and declares what's missing: a default namespace for an element written with a namespace and no prefix, your prefix for an element written with one, and a generated prefix (`ns1`, `ns2`, and so on) for an attribute in a namespace that has no prefix in scope. An element written with no namespace argument, or with a `null` one, gets no declaration, so under a default namespace a reader puts it in that namespace. An element written with an empty namespace is in no namespace: under a default namespace the writer adds `xmlns=""`.

### Indentation

With `Indented` set, only elements get a line break and indentation. An element that holds text is written on one line. Comments and processing instructions are written where the writer is, with no line break before them.

### What isn't checked

- `WriteRawValue` copies its input without checking or escaping it. The `skipInputValidation` parameter has no effect.
### Differences from Utf8JsonWriter

- There's no property-name step. Structure comes from `WriteStartElement` and `WriteEndElement`, and attributes are written on the open start tag.
- Validation is on by default and also covers names and namespaces. `SkipValidation` doesn't turn off the single-root check or the limits.
- `Dispose` throws when the document is incomplete.

### Differences from System.Xml.XmlWriter

- The output is UTF-8 only, to an `IBufferWriter<byte>` or a `Stream`. There's no `TextWriter` or `StringBuilder` target.
- There's no `WriteDocType`, `WriteEntityRef`, `WriteStartDocument`, or `WriteEndDocument`. The declaration is written for you, and nothing closes open elements for you.
- `Reset` lets one instance write many documents.
- Typed values have their own methods, in place of `WriteValue` overloads and `XmlConvert`.
