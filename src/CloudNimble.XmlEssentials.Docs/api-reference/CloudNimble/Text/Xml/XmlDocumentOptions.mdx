## Summary

Options for [XmlDocument.Parse](/api-reference/CloudNimble/Text/Xml/XmlDocument#parse).

## Usage

# Usage

Pass a constructed options struct into `XmlDocument.Parse`:

```csharp
var options = new XmlDocumentOptions
{
    MaxDepth = 32,
    CommentHandling = XmlCommentHandling.Allow,
    MaxDocumentByteCount = 1_048_576,
};
using var document = XmlDocument.Parse(utf8, options);
```

Omit the argument for defaults: comments skipped, insignificant whitespace between elements skipped, every max-* at `0` (table defaults).

## Remarks

A max-* of 0 means the default from the DoS table, except [XmlDocumentOptions.MaxDocumentByteCount](/api-reference/CloudNimble/Text/Xml/XmlDocumentOptions#maxdocumentbytecount)
which stays unbounded. Construct with `new XmlDocumentOptions()` so
[XmlDocumentOptions.CommentHandling](/api-reference/CloudNimble/Text/Xml/XmlDocumentOptions#commenthandling) defaults to [XmlCommentHandling.Skip](/api-reference/CloudNimble/Text/Xml/XmlCommentHandling).

## Examples

# Examples

Cap an untrusted payload:

```csharp
using var document = XmlDocument.Parse(stream, new XmlDocumentOptions
{
    MaxDocumentByteCount = 64 * 1024,
    MaxDepth = 16,
});
```

Keep insignificant whitespace as text nodes with `WhitespaceHandling = XmlWhitespaceHandling.All`.

## Best Practices

# Best Practices

- Construct with `new XmlDocumentOptions()`. Do not use `default`.
- Set `MaxDocumentByteCount` on `Parse(Stream)` for untrusted sources.
- Keep `CommentHandling` at `Skip` unless the infoset must round-trip comments.

## Patterns

# Patterns

**Untrusted input.** Set `MaxDocumentByteCount` and `MaxDepth` together. A stream that exceeds the cap throws `XmlException` before the tokenizer runs on the overflow.

**Comments.** `Skip` (default) drops comments. `Allow` stores them. `Disallow` throws.

**Reader.** The same limits apply if you tokenize first and call `XmlDocument.ParseValue`.

## Considerations

# Considerations

`XmlDocumentOptions` is a struct. `new XmlDocumentOptions()` runs the constructor and sets `CommentHandling` to `Skip`. `default(XmlDocumentOptions)` leaves `CommentHandling` at `Disallow` (enum zero). Prefer `new`.

A max-* of `0` means “use the table default”:

| Property | When 0 |
| --- | --- |
| `MaxDepth` | 64 |
| `MaxAttributeCount` | 1000 |
| `MaxNameByteCount` | 1024 |
| `MaxCommentByteCount` | 1,048,576 |
| `MaxTextByteCount` | 16,777,216 |
| `MaxDocumentByteCount` | unbounded (stays 0) |

Limits are forwarded to `Utf8XmlReader`. `MaxDocumentByteCount` is also enforced on `Parse(Stream)` as the stream is read.
