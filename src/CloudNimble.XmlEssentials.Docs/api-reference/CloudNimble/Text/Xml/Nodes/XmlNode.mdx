## Usage

# Usage

`XmlNode` is the mutable base type. Parse a document to its root element, write it, or deep-clone it.

```csharp
XmlNode? root = XmlNode.Parse("<e a=\"1\">x</e>");
root!.WriteTo(writer);
var copy = root.DeepClone();
```

`ParseValue(ref Utf8XmlReader)` captures the current element. `ToString` is the XML markup for that node.

## Examples

# Examples

```csharp
var reader = new Utf8XmlReader("<e>z</e>"u8);
var node = XmlNode.ParseValue(ref reader);
Console.WriteLine(node);
```

## Best Practices

# Best Practices

Switch on `ValueKind` (or pattern-match the concrete type) before reading element-only members. Catch `XmlException` around `Parse`.

## Patterns

# Patterns

**Read then edit.** `XmlDocument.Parse` → `CloneNode` → mutate. Or `XmlNode.Parse` when you do not need the pooled document.

## Considerations

# Considerations

`Parent` is null until the node is added to an `XmlNodeList` or `XmlAttributeNodeList`. The default `NamespaceUri` getter is null; elements and attributes override it.

`Parse` requires a document element. Prolog comments/PIs are discarded.
