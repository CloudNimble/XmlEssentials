## Definition

## Syntax

```csharp
CloudNimble.Text.Xml.XmlSerializer
```

## Summary

Serializes CLR values to UTF-8 XML and back. Analogous to `JsonSerializer`.

## Remarks

Every overload resolves an [XmlTypeInfo](/api-reference/CloudNimble/Text/Xml/Serialization/XmlTypeInfo) and then goes through one of the internal
`Read` or `Write` methods in this file. All reading is done by [Utf8XmlReader](/api-reference/CloudNimble/Text/Xml/Utf8XmlReader) and
all writing by [Utf8XmlWriter](/api-reference/CloudNimble/Text/Xml/Utf8XmlWriter).

## Properties

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> IsReflectionEnabledByDefault

Gets whether options with no [XmlSerializerOptions.TypeInfoResolver](/api-reference/CloudNimble/Text/Xml/XmlSerializerOptions#typeinforesolver) fall back to
[DefaultXmlTypeInfoResolver](/api-reference/CloudNimble/Text/Xml/Serialization/DefaultXmlTypeInfoResolver). It is [`true`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool) unless the
`CloudNimble.Text.Xml.XmlSerializer.IsReflectionEnabledByDefault` switch is [`false`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool).

