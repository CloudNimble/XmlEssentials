```csharp
CloudNimble.Text.Xml.Serialization.XmlPropertySetter<TDeclaring, TValue>
```

## Summary

Represents a method that sets the value of a property or field on an object.

## Remarks

The object is passed by reference so that the method can set a member of a value type in place. For a
reference type, the method sets the member of the object that *instance* refers to and
leaves the reference as it is.

## Type Parameters

- `TDeclaring` - The type that declares the property or field.
- `TValue` - The type of the property or field.

## Examples

```csharp
XmlPropertySetter<Point, int> setX = static (ref Point point, int value) => point.X = value;
```
