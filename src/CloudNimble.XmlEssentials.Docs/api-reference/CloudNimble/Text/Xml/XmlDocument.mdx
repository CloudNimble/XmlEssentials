## Usage

# Usage

Parse UTF-8 XML into a pooled, immutable document. Dispose the instance to return the rental.

```csharp
using var document = XmlDocument.Parse("<Person id=\"1\"><Name>Ada</Name></Person>");
var root = document.RootElement;
Console.WriteLine(root.GetAttribute("id").GetInt32());
Console.WriteLine(root.GetChild("Name").GetString());
```

Overloads accept `string`, `ReadOnlySpan<char>`, `ReadOnlySpan<byte>`, `ReadOnlySequence<byte>`, and `Stream`. `ParseValue(ref Utf8XmlReader)` captures the current element as a document. `TryParse` returns false on well-formedness errors instead of throwing.

## Examples

# Examples

UTF-8 span and stream:

```csharp
using var fromUtf8 = XmlDocument.Parse("<e>1</e>"u8);
using var stream = new MemoryStream("<e>2</e>"u8.ToArray());
using var fromStream = XmlDocument.Parse(stream);
```

Keep comments and round-trip them:

```csharp
using var document = XmlDocument.Parse(
    "<!--hi--><e/><!--tail-->",
    new XmlDocumentOptions { CommentHandling = XmlCommentHandling.Allow });
```

Clone the root into a mutable tree:

```csharp
var node = (XmlElementNode)document.RootElement.CloneNode();
node.SetAttribute("id", "1");
```

## Best Practices

# Best Practices

- Always dispose. The extra buffer and row store are `ArrayPool` rentals.
- Prefer `Parse(ReadOnlySpan<byte>)` when you already have UTF-8. `Parse(string)` encodes first.
- Set `MaxDocumentByteCount`, `MaxDepth`, and `MaxAttributeCount` on untrusted input.
- Use `CommentHandling.Allow` only when comments must round-trip. The default skips them.
- For lookup, `TryGetChild` / `TryGetAttribute` avoid exceptions on missing names.

## Patterns

# Patterns

**Pooled parse.** `using var document = XmlDocument.Parse(utf8);` then read through `RootElement`. Do not cache the document instance.

**Cursor.** `XmlElement` is a struct cursor. Enumerate children and attributes; do not store cursors after `Dispose`.

**Fragment.** `ParseValue(ref reader)` builds a document whose root is the current start tag. Empty elements stop without consuming the next sibling.

**Mutation.** Call `CloneNode` (or `XmlNode.Parse`) when you need to edit. The immutable document does not change.

## Considerations

# Considerations

`XmlDocument` is analogous to `JsonDocument`. The parse buffer is rented from `ArrayPool<byte>`. Use after `Dispose` throws `ObjectDisposedException`.

Prolog and epilog comments or processing instructions are preserved for `WriteTo` and are not children of `RootElement`. The XML declaration is `XmlDeclarationInfo?`, not a mutable `XmlDeclarationNode`.

`WriteTo` emits the captured declaration when one was present, then the prolog, root, and epilog. Pass `OmitXmlDeclaration = true` on the writer when you want a fragment without a declaration and the source had none.

A max-* of `0` on `XmlDocumentOptions` means the DoS table default, except `MaxDocumentByteCount` which stays unbounded. Comments default to `Skip`.
