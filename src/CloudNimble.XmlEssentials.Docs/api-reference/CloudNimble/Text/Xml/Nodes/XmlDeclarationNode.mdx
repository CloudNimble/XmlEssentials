## Summary

A mutable XML declaration. Immutable documents use [XmlDeclarationInfo](/api-reference/CloudNimble/Text/Xml/XmlDeclarationInfo) instead.

## Usage

`XmlDeclarationNode` is the XML declaration, `<?xml version="1.0" encoding="utf-8"?>`, as a node you can set up and write. `Version` defaults to `1.0`, `Encoding` to `utf-8`, and `Standalone` to `null`, which leaves `standalone` out.

You seldom need it. A `Utf8XmlWriter` writes a declaration by itself unless `XmlWriterOptions.OmitXmlDeclaration` is `true`, as the first half of this example shows. Use the node when you want to state the declaration yourself, for example to write `standalone="yes"`. Write it first, to a writer that omits its own declaration.

```csharp
var order = new XmlElementNode("Order");
order.SetAttribute("id", "1042");
order.AddElement("Item").InnerText = "Keyboard";

var buffer = new ArrayBufferWriter<byte>();
var options = new XmlWriterOptions { Indented = true, NewLine = "\n" };
using (var writer = new Utf8XmlWriter(buffer, options))
{
    order.WriteTo(writer);
}

output.WriteLine(Encoding.UTF8.GetString(buffer.WrittenSpan));

buffer.ResetWrittenCount();
options = new XmlWriterOptions { OmitXmlDeclaration = true };
using (var writer = new Utf8XmlWriter(buffer, options))
{
    new XmlDeclarationNode { Version = "1.0", Standalone = true }.WriteTo(writer);
    order.WriteTo(writer);
}

output.WriteLine(Encoding.UTF8.GetString(buffer.WrittenSpan));
```

The code produces the following output:

```xml
<?xml version="1.0" encoding="utf-8"?>
<Order id="1042">
  <Item>Keyboard</Item>
</Order>
<?xml version="1.0" encoding="utf-8" standalone="yes"?><Order id="1042"><Item>Keyboard</Item></Order>
```

[View the complete sample on GitHub](https://github.com/CloudNimble/XmlEssentials/blob/main/src/CloudNimble.XmlEssentials.Samples/29_BuildWithXmlNode.cs)

## Considerations

- `WriteTo` writes the declaration text directly, and the writer doesn't record that a declaration was written. With a writer whose `OmitXmlDeclaration` is `false`, the output has two declarations and isn't well formed. Create the writer with `OmitXmlDeclaration = true`.
- The node must be written before anything else. It doesn't belong in an element's `Children`; added there, it's written inside the element.
- `Version` and `Encoding` are written as they are, without validation. XmlEssentials writes UTF-8 only, so leave `Encoding` at `utf-8`. Setting `Version` to `1.1` changes the declaration, not the writer; set `XmlWriterOptions.Version` as well.
- `XmlNode.Parse` never returns this node, and a tree has no document node to hold it. The declaration of a parsed document is `XmlDocument.Declaration`, an `XmlDeclarationInfo`.
- This is the only node type whose `ValueKind` is `XmlDeclaration`.
